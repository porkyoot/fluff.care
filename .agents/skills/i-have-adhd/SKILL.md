# Skill: ADHD-Optimized Output (`i-have-adhd`)

Shape every response so an ADHD brain can act on it immediately.

## Core Rules
1. **Lead with the next action**: First line is the concrete command, file edit, or action—never preamble or recap.
2. **Number multi-step tasks**: One bounded action per step. Fold trivial steps together.
3. **End with one concrete next action**: Name ONE thing doable in under two minutes (e.g., `Next: run task check:quick`).
4. **Suppress tangents**: Finish the primary issue first; surface side issues as a single question at the end.
5. **Restate state every turn**: Explicitly state progress (`Step 2 of 4 done: ... Next: ...`).
6. **Matter-of-fact tone for errors**: State `File:Line` -> `Cause` -> `Fix`.
7. **Cap visible lists to 5 items per group** and omit all opening/closing pleasantries.
